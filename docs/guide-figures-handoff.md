## 1. 这是什么项目

见字是 2026 知乎黑客松校园季「知识炼金场」的桌面网页。一张桌子上铺着从知乎挑出来的回答，一次只看清中间几张。读者拖桌子、用键盘跳到下一张，点中的那张会翻过来，读完开头再去知乎。

它不是学习工具，不把回答炼成要点。读者要遇见的是写字的人。

引导卡不是浮在桌上的教程，是第一次打开时**占住灯下那一格的一张剪报**。和周围的回答同一套纸、同一套拖动、同一套翻转。刷新之前它一直在；下次打开这一格换回池子里的回答。

---

## 2. 为什么要这些图

现在的引导卡是一段说明文字。桌上另外几十张卡也是大段正文。读者天生跳过说明书。操作（移动、翻开、收藏、换视图）被埋在字里。

图要做的事：让人在三秒内看见「手往哪放、键是哪几个」，而不是再读一遍底栏那行字。

这些图只给引导卡用，不进内容池，不印到知乎回答上。池子里的正文仍是接口给的原文开头，一个字不改。

## 3. 你要交付什么

文件放到 `jianzi/public/guide/`。前端按 `src` 原样引用。缺文件不要占位、不要 404 图。

| 文件 | 上哪一面 | 画面里必须有什么 | 画面里不要有什么 |
| --- | --- | --- | --- |
| `move.webp` | 正面 | **WASD** 与 **方向键** 两套键，表示同一件事：把桌子移到下一张。两套键要画成实体键帽或报纸示意图，一眼能认出。可以画一张卡在键的「前面」被送到眼前。 | 不要写成「请按 WASD」。不要游戏手柄。不要 WASD 和方向键各说各的、好像两套功能。 |
| `pointer.webp` | 正面 | 两件事并置或上下排：**(1) 笔记本触控板，两指平移**；**(2) 鼠标**，滚轮上下、Shift+滚轮左右、按下中键拖动。这是 Windows 用户会伸手去做的动作。 | 不要画成 macOS 宣传图。触控板和鼠标都要能单独看懂。不要浏览器缩放图标。 |
| `open.webp` | 背面 | 点中间那张卡，或按 **Enter / 换行**，纸翻过来。翻过去是原文开头，撕口下面才去知乎。 | 不要画成 App 弹窗。不要「点击这里」箭头贴在真实 UI 截图上。不要假知乎界面。 |
| `file.webp` | 背面 | 按住一张卡拖到屏幕**左边**三枚标签（稍后读 / 值得再读 / 想转给谁）。旁边用小键帽标 **1 / 2 / 3** 对应这三枚。 | 不要心形、五星、点赞。收藏不是喜欢。 |
| `views.webp` | 背面 | 屏幕**右边**三枚竖排索引标签：紧凑、宽松、列表。小键帽 **8 / 9 / 0** 依次对应。 | 不要汉堡菜单、不要底部 Tab Bar。 |

正面两张是进门就要看见的。背面三张跟翻开的说明走，读者点开引导卡才看到。

### 技术规格

- 格式：WebP 或 PNG。优先 WebP。不要 JPG。
- 宽度：720px（卡片内容区大约 340–380 CSS 像素，2x 足够）。高度随构图，不要做成满屏海报。
- 单张体积：小于 120KB。
- 比例：横图，约 3:2 或 2:1。竖图会把卡片正面顶爆。
- 透明：不要透明底。插图是印在报纸上的一块色版，四边可以略毛，但不要悬在透明棋盘上。
- 文字：可以画键帽上的字母（W A S D、↑↓←→、1 2 3、8 9 0、Enter）。不要写句子、不要英文说明段落、不要水印、不要 Logo。中文标签如果出现，只允许「稍后读 / 值得再读 / 想转给谁 / 紧凑 / 宽松 / 列表」这些产品里已有的词。
- 交付时在本文件末尾补一张表：文件名、实际宽高、体积、你自己的验收句（缩小到 360px 宽是否仍能看出是什么键、什么手势）。

## 5. 审查时盯什么

每张图反复看这几件事，不要一次过就停：

1. 缩小到卡片上的实际宽度（约 360px），还能不能立刻认出键或手势。
2. 有没有变成 UI 截图、教程箭头、游戏 HUD。
3. 有没有玻璃、渐变、3D、贴纸、胶带。
4. WASD 和方向键是否在说同一件事。
5. 触控板和 Windows 鼠标是否都在，没有只画苹果产品。
6. 左标签是收藏，右标签是视图，没有画反。

不合格就改同一张，不要另开一套构图充数。
