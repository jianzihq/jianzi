## 2. 这一段实际做了什么（代码已在）

### 2.1 Windows 与快捷键（`46d0f31`，在 `main`）

`Desk.tsx` 的 `useGesture`：

- 普通滚轮：平移桌子
- Shift+滚轮：横移（Windows 竖滚轮的横滑）
- Ctrl+滚轮 / 触控板捏合：在**未翻开、非列表**时 `preventDefault`，增量加进平移，页面不缩放。专栏和列表里不截，留给浏览器缩放
- 中键拖（`buttons: [1, 4]`）平移；`mousedown` 中键 `preventDefault` 以免自动滚动
- Enter：翻开灯下那张
- 1 / 2 / 3：灯下那张收进稍后读 / 值得再读 / 想转给谁（引导卡除外）
- 8 / 9 / 0：紧凑 / 宽松 / 列表
- HUD：`拖动 / 中键 · 滚轮 · 方向键 / WASD · Enter · 1 2 3 · 8 9 0`（接上喜恶后在 Enter 后加了「右键」）

**决定（已定）**：不要把捏合缩放加回来。桌子是铺满窗口的相机，主操作是两指/滚轮平移；捏合和两指只差几毫米，加回缩放会把灯和相机一起拉变形。Ctrl+滚轮在 Windows 上原生是缩放，不是平移；现在截住只是为了不炸布局，和普通滚轮几乎重复。不必再改，除非只改成「拦住但不平移」（捏合就不会把桌子弹开）。**本任务不要动它。**

### 2.7 发牌与桌面（实现时补）

光把 `orderDeck` 的结果交给 Desk 接不上。原来格子到卡片的映射是 `(7i + 11j) mod n`，整副牌均匀铺满网格：牌序怎么排，桌上各领域的密度都不变；牌组一变短，屏幕上每一张卡同时换掉。

`lib/deal.ts` 改为发牌（`3634265`，本次修订后改为留在原位）：

- 格子记住发给它的卡，整个访问期间不变。只有第一次出现的格子才发牌。
- 按 `orderDeck` 的顺序一轮一轮发，跳过屏幕上已有的和大约一屏以内刚发过的。每次表态从头开始新的一轮，所以读者逛过一大圈再表态，没碰过的领域也会先出。
- `lib/deck.ts` 的 `spread` 先把池子按领域穿插：池子按领域分块存，原样发会一整屏同一个领域。`orderDeck` 的规则没改。
- **牌组和桌面分开**：表态只改变之后发什么。本次访问里表过态的卡留在原格，带丝带尾巴。上次访问不喜欢的卡，刷新后不会再发出来：服务端发牌时还不知道浏览器里的喜恶，这样的卡如果落在首屏，喜恶读到后那一格会立刻重发。
- **喜欢的卡会回来，但很少**：它排在牌组最后，每次发出后要冷却两轮（`2 × 牌组张数` 次发牌）才能再发，回来时带红色丝带尾巴。冷却按发牌次数算，不用随机权重：牌只有 60 张，随机容易让它连着出现或者久久不来，确定的规则也便于测和演。上次访问喜欢过的卡可能直接出现在首屏上，带红尾巴，这是有意保留的。
- 列表视图照旧列出全部卡，表过态的也在，带丝带尾巴，可以右键取消。

## 3. 讨论过后敲定的手势模型

### 3.1 卡片不能拖

桌上拖的是**桌子**。卡片钉在格子里。按住一张卡移动，走的是相机，卡不会被拎走。

`PRODUCT.md`「用户拖动去找下一张」指的是这个，不是揭牌。

`HANDOFF.md` 里「像一言那样左右滑」是更早的手机牌组设想，已被卡片桌取代。

`DESIGN.md` §9「拖空白=挪桌，拖卡片=左扔不喜欢 / 右扔喜欢」是**已定未实现**，并且自己写了代价：紧凑视图没有空白，按在卡上会误扔。后来收藏又占了长按。同一指针挤了三件事，平移赢了，扔没做。

**决定（已定）**：不要在桌上做扔卡片。不要为了喜恶重新让卡片可拖。

### 3.2 喜恶放哪里（已定，本任务要做）

反向推荐一定要做，所以一定要有喜欢/不喜欢。

否决：

1. **长按出喜恶 / 悬停出喜恶**。长按已经给收藏提起。悬停出控件不像报纸，评委鼠标不停就看不见。
2. **左键**。左键是翻开，不能抢。
3. **知乎式话题标签贴在正文里**。喜恶不是话题，也不是赞同。

采用：

**正位（改为书签，Teethe 看过实物后定）**：卡片翻开后，专栏纸右边缘下压着两条丝带书签，伸到桌上，横排写「喜欢」「不喜欢」，尾部剪成燕尾。根部真的压在纸下（丝带渲染在舞台里、纸之前）。跟屏幕固定，长文读到底仍在手边。

- 每张卡的高度、间距、角度、长度按卡片 id 固定随机（`lib/paper.ts` 的 `ribbonPose`），两条近乎平行，尾部夹角限制在 −2° 到 +2.5°。「喜欢」总在上。
- 选中那条抽出更长：喜欢朱红，不喜欢墨色。再点收回，点另一条切换。
- 放回桌上后，那张卡右边缘露出同色的一截丝带尾巴，列表里也一样。
- 引导卡没有书签。

~~**正位（方案三，改过）**：卡片翻开后，两枚印记放在专栏**右侧的桌子上**（纸的右边，不是印在正文上）。像校对时搁在旁边的章。点「喜欢」或「不喜欢」。已标记的再点一下可取消（或点另一枚以切换）。引导卡没有这两枚。~~ 做出来是两块浮在桌上的牛皮纸，不属于任何东西，读起来像按钮。

**快手（右键，不是左键）**：在**未翻开的卡片**上右键，拦住浏览器菜单，弹出一小条和左栏收藏同一牛皮纸色的菜单，**只有**「喜欢」「不喜欢」（已标记则可取消）。不要「打开」，不要收藏三项，不要复制链接。

**专栏里不要抢右键。** 正文要能划词复制，系统菜单留给这件事。专栏里只点纸边的书签。

两处写**同一份** prefs。菜单不要做成 OS 灰底右键条。

引导卡、列表里若也要表态：列表可右键或沿用同一套；引导卡禁止。

快捷键（4/5 之类）讨论过，**未拍板**。不要擅自加，除非现有 1–3、8–9–0、Enter 完全碰不上且 Teethe 补一句。

### 3.3 插图与文案（已定）
